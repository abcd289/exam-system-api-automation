# 自动化测试框架执行流程图

## 1. 框架执行流程

本项目基于 Python + Pytest + Requests 搭建接口自动化测试框架，采用 Excel 数据驱动方式管理测试用例，通过统一请求封装、数据提取、响应断言和数据库校验，实现接口自动化测试。

## 2. 执行流程

1. 通过 `run.py` 启动自动化测试。
2. Pytest 加载测试用例，读取 Excel 中的接口请求数据。
3. 对测试数据进行参数化，生成独立测试用例。
4. 调用统一请求方法发送 HTTP 请求。
5. 根据测试场景提取 JSON 响应数据、Cookie 或数据库数据，并保存为后续请求可使用的变量。
6. 执行响应断言，校验接口返回结果。
7. 根据用例配置决定是否执行数据库校验。
8. 记录测试执行结果，通过 Allure 生成测试报告。

## 3. 核心实现

- **数据驱动：** 使用 Excel 管理测试数据和预期结果。
- **请求封装：** 使用 Requests 统一处理 HTTP 请求。
- **数据关联：** 支持 JSON、Cookie 和 SQL 数据提取。
- **断言校验：** 校验接口响应及数据库数据。
- **测试报告：** 使用 Allure 展示测试步骤和执行结果。
